This project reverses the familiar CAPTCHA idea. A compatible client requests a server-generated challenge, computes the answer, and receives a short-lived token to access a structured machine-readable archive.

SERVER-SIDE CHALLENGE / TOKEN-GATED ARCHIVE

Machine protocol discovery:

/.well-known/ai-captcha.json

Supabase gateway endpoint:

https://eopvkwhcgznvubesaszv.supabase.co/functions/v1/ai-captcha-gateway

Request sequence:

POST {"action":"challenge"} POST {"action":"verify","challenge_id":"...","answer":{"answer":1234}} POST {"action":"site"} // Authorization: Bearer <access_token>

Limits:

Challenge expiry: 180 seconds Maximum attempts: 3 Access token expiry: 600 seconds Token uses: 1
